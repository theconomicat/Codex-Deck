# Codex Deck 사용 가이드

[← README](../README.ko.md) · [English](guide.md)

## 설치

Apple silicon Mac에서는 [최신 릴리스](https://github.com/theconomicat/Codex-Deck/releases/latest)의 `Codex-Deck-macos.zip`을 받아 압축을 풉니다. macOS 13+와 로그인한 Codex 데스크톱 앱이 필요하며 Swift나 Node.js를 설치할 필요는 없습니다. 다운로드 검증용 `SHA256SUMS.txt`도 함께 제공합니다.

Intel Mac이나 소스 빌드는 Swift 6와 Git을 준비한 뒤 README의 빌드 명령을 사용하세요. Node.js는 개발 테스트에만 사용합니다.

기존 앱을 종료하고 `Codex Deck.app`을 `/Applications`로 옮깁니다. 메뉴 막대 앱이므로 Dock 창이 계속 열려 있지는 않습니다. 릴리스와 로컬 빌드는 임시 서명되며 Apple 공증을 받지 않았습니다. 실행이 차단되면 다운로드·소스를 확인한 뒤 시스템 설정 → 개인정보 보호 및 보안에서 해당 앱의 열기 옵션을 사용하세요.

**Enable Direct Switching…**에서 설정 창을 엽니다. 진행 중인 작업을 마친 뒤 **Codex 재시작 · 직접 전환 연결**을 누르고, Codex 기본 창 하나에서 입력창이 보이는 채팅을 여세요. 전환에 성공하면 메뉴 막대에 프리셋 이름이 잠시 표시되고 메뉴에 `Applied:`가 나타납니다. 설정 완료만으로 모델 전환 성공까지 확인된 것은 아닙니다.

단축키는 Codex가 맨 앞일 때 동작합니다. 모델·추론 수준은 본인 계정에서 지원해야 합니다. Codex가 확인을 요청하면 Mac에서 완료하세요. 지원하지 않는 조합을 임의로 다른 값으로 바꾸지는 않습니다.

## 키보드 단축키

Codex Deck은 **Codex가 맨 앞일 때 `⌘⌃1–5`만** 프리셋용으로 우선 처리합니다. Codex에 같은 조합으로 지정된 동작은 그동안 실행되지 않습니다. `⌃⇧M`을 비롯한 나머지 단축키는 가로채지 않습니다. 다른 앱으로 전환하거나 Codex Deck을 종료하면 다섯 조합의 등록이 해제됩니다.

앱이 `~/.codex/keybindings.json`을 수정하지는 않습니다. 이전 충돌 해결용 예제를 직접 적용했다면 해당 `null` 항목이 채팅·탭·모드 단축키를 별도로 끄므로 Codex Deck을 종료해도 유지됩니다. 기본값으로 복원하려면 추가했던 항목만 지우고 다른 사용자 설정은 보존하세요. `CODEX_HOME`을 변경했다면 해당 폴더를 사용합니다.

## 휴대폰 연결

1. 직접 전환 설정을 마치고, Codex 기본 창 하나에 **저장된 채팅**과 입력창을 보이게 둡니다.
2. Mac을 깨어 있게 두고 두 기기를 같은 신뢰할 수 있는 개인 Wi-Fi에 연결합니다.
3. **Web Deck… → Start Web Deck**에서 QR을 스캔하거나 **Copy Pairing Link**의 전체 주소를 엽니다. IP 주소만으로는 기기가 연결되지 않습니다.
4. 사용량 게이지를 눌러 대상 채팅을 확인한 뒤 프리셋을 사용합니다.

서버는 기본적으로 꺼져 있고 로그인할 때 자동으로 켜지지 않습니다. 설정 창만 닫으면 계속 실행됩니다. 서버를 중지하거나 보조 앱을 재시작하면 연결이 해제되므로 다시 켜고 페어링하세요.

연결 링크는 **5분 동안 한 번만** 사용할 수 있습니다. 다른 기기는 **New Pairing Link**로 연결합니다. 연결 세션은 최대 8시간이며 **Disconnect All Devices**로 모두 해제할 수 있습니다. 연결 링크는 타인에게 공유하지 마세요.

지원 브라우저에서는 **Usage → Enter full screen**을 사용합니다. iPhone에서는 Safari의 **공유 → 홈 화면에 추가**로 열 수 있으며 별도로 페어링해야 할 수 있습니다. 가로·세로 화면을 모두 지원합니다. 단축키와 달리 휴대폰 조작은 Mac의 다른 앱이 앞에 있어도 가능합니다.

연결은 전송 암호화가 없는 **로컬 HTTP**입니다. 신뢰하는 네트워크에서 사용하고 인터넷에 포트를 열지 마세요. 게스트 Wi-Fi의 기기 간 통신 차단이나 Mac 방화벽·로컬 네트워크 권한도 확인합니다. Wi-Fi나 IP가 바뀌면 서버를 재시작하세요. `127.0.0.1` 주소는 Mac에서만 열립니다. [보안 안내](../SECURITY.md)

## 버튼 설정

Mac 메뉴의 **Edit Button Settings…**에서 파일을 엽니다.

```text
~/Library/Application Support/Codex-Usage/presets.json
```

업데이트할 때 설정을 유지하도록 폴더에는 이전 앱 이름을 사용합니다. JSON을 여는 편집기가 없다면:

```bash
open -a TextEdit "$HOME/Library/Application Support/Codex-Usage/presets.json"
```

주석이나 마지막 쉼표 없이 서식 없는 텍스트로 저장합니다. [전체 예제](../presets.example.json)를 기준으로 수정하고, 편집기 검증에는 [스키마](presets.schema.json)를 사용할 수 있습니다.

| 항목 | 의미 |
| --- | --- |
| `version` | 설정 형식이므로 `1`을 유지합니다. |
| `slot` | `1`~`5`를 각각 한 번씩 사용합니다. 덱 위치와 `⌘⌃숫자`를 지정하며 배열 순서는 무관합니다. 두 키를 바꾸려면 번호를 교환합니다. |
| `model` | Codex 표시 이름 또는 ID. 예: `GPT-6 Astra`, `gpt-6-astra`. `GPT-6 Sol`과 `GPT-6.1 Sol`은 서로 다릅니다. |
| `effort` | 지원하는 값: `none`, `minimal`, `low`, `medium`, `high`, `xhigh`, `max`, `ultra`. Extra High는 `xhigh`입니다. |
| `label` | 웹 버튼 이름. 생략 가능하며 앞뒤 공백·제어 문자 없이 1~32자입니다. 생략하면 모델 이름을 자동 표시합니다. |

저장하면 다음 단축키 또는 웹 갱신(화면이 보일 때 약 5초)부터 적용됩니다. **Reload Button Settings**는 Mac 메뉴도 바로 갱신합니다. JSON 오류가 있으면 마지막 정상 설정을 유지하며, 새로 실행했을 때 파일이 잘못돼 있으면 기본값을 사용합니다. 이전 3개 슬롯 설정은 같은 폴더에 백업한 뒤 이전합니다.

`label`은 웹 표시만 바꿉니다. 툴팁·스크린 리더 이름·Mac 메뉴에는 실제 모델이 유지됩니다. 다섯 키는 모델 프리셋이며 `⌘⌃` 조합은 고정입니다. 임의의 매크로를 실행하지 않습니다.

Codex 모델을 바꾸지 않고 파일만 검사하려면:

```bash
"/Applications/Codex Deck.app/Contents/MacOS/CodexUsage" \
  --validate-presets "$HOME/Library/Application Support/Codex-Usage/presets.json"
```

## 평소 조작

**Models / Presets**로 전체 모델 목록과 저장된 키를 오갑니다. 가로바는 손을 뗄 때 현재 모델의 추론 수준을 바꿉니다. 둘 다 JSON을 수정하지 않으므로 프리셋을 다시 누르면 저장된 조합으로 돌아갑니다.

**Mac mic**는 Mac의 Codex 받아쓰기를 시작·중지하고 입력창에 글을 넣습니다. 메시지는 전송하지 않습니다. 마이크 권한은 Mac에서 허용하세요. 덱을 닫기 전에 녹음을 중지해야 하며, 연결이 끊겨도 녹음 중지가 보장되지는 않습니다.

**Requests**는 현재 채팅의 지원되는 질문·승인 요청이 있을 때 나타납니다. 내용을 확인한 뒤 답하세요. 지원하지 않는 요청은 Codex에서 완료합니다. [전체 조작 설명 →](codex-micro.md)

## 사용량과 상태 색상

<img src="menu-bar-preview.png" alt="Menu bar quota: 94 percent remaining" width="185" />

퍼센트는 **남은 한도**입니다. 30초마다 로컬 Codex 사용량 이벤트를 확인하며 **Refresh Usage**로 즉시 읽을 수 있습니다. `Data as of`는 기록 시각이고, 새로고침이 서버에 새 사용량을 요청하지는 않습니다. 기록이 없거나 만료되면 새 이벤트가 생길 때까지 알 수 없음으로 표시합니다.

테두리는 현재 채팅에 따라 흰색 대기, 연두색 읽지 않은 완료, 하늘색 작업 중, 살구색 답변 필요, 빨간색 채팅 오류로 바뀝니다. 상태 불명·연결 끊김은 회색입니다. 웹 화면이 보일 때 약 5초마다 확인합니다. [상태를 읽는 방식과 제한 →](codex-micro.md#status-frame)

## 자동 실행·업데이트·삭제

최초 연결 후 **Launch at Login**과 **Open Codex Automatically**를 켜면 보조 앱 시작 시 연결 모드로 Codex를 엽니다. Codex가 이미 일반 실행 중이면 작업을 마친 뒤 설정에서 다시 연결하세요. 사용자가 닫은 Codex를 계속 다시 열지는 않습니다. Web Deck 서버는 직접 시작해야 합니다.

업데이트할 때는 보조 앱을 종료하고 `/Applications`의 앱을 교체합니다. Codex-Usage에서 올리는 경우 이전 앱도 종료하고 제거하세요. JSON은 앱 밖에 유지됩니다. 이름 변경 뒤 로그인 설정을 확인하고 휴대폰은 다시 연결합니다.

삭제할 때는 로그인 실행을 끄고 앱을 종료해 휴지통으로 옮깁니다. Codex도 종료 후 일반 실행하면 디버깅 연결이 닫힙니다. 저장된 프리셋까지 지울 때만 `~/Library/Application Support/Codex-Usage`를 삭제하세요.

## 문제 해결

| 증상 | 확인 |
| --- | --- |
| 단축키가 반응하지 않음 | Codex를 맨 앞으로 가져오고, 보조 앱 실행과 JSON을 확인합니다. |
| 연결·입력창 구분 오류 | 기본 Codex 창과 저장된 채팅 입력창을 하나만 보이게 두세요. 작업을 마친 뒤 다시 연결합니다. |
| 모델·추론 수준 거부 | 계정이 지원하는 모델·수준과 Codex의 확인 요청을 살펴봅니다. |
| 전환 시간 초과 | 확인 단계만 실패했을 수 있으므로 Mac의 실제 선택을 보고 재시도합니다. |
| 휴대폰 접속 불가 | 같은 Wi-Fi, 깨어 있는 Mac, 서버 실행, 방화벽, 기기 간 통신을 확인하고 새 전체 링크로 연결합니다. |
| 채팅·프리셋·요청이 바뀌었다는 안내 | 새로고침하고 대상 채팅을 확인합니다. |
| 클릭음이 안 들림 | 미디어 볼륨·음소거·브라우저 소리 설정을 확인합니다. 앱이 강제로 해제할 수는 없습니다. |
| 녹음 상태 불명·요청 누락 | Mac의 Codex에서 해당 작업을 확인하고 완료합니다. |
| 사용량이 오래됨 | Codex 작업으로 새 사용량 기록이 생긴 뒤 새로고침합니다. |

숫자 단축키가 채팅을 선택한다면 선택적으로 [키 바인딩 예제](codex-keybindings.example.json)를 `~/.codex/keybindings.json`에 합칠 수 있습니다. 기존 항목을 보존하세요. 예제에 적힌 Command/Control 숫자 이동도 해제되며, 추가한 `null` 항목을 지우면 복원됩니다. 앱은 이 설정을 자동 설치하지 않습니다. `CODEX_HOME`을 바꿨다면 해당 폴더를 사용합니다.

Codex 내부 구조에 의존하는 연결입니다. 오프라인 테스트는 화면과 연결 코드의 동작을 검사하며 모든 실제 데스크톱 버전·휴대폰 동작을 검증한 것은 아닙니다. 구현과 검증 범위는 [직접 전환](model-switching.md), [조작 제한](codex-micro.md#verification-and-current-limits), [기여 안내](../CONTRIBUTING.md)에 있습니다.
